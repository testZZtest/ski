# Web research

1. Break the user's question into 2-4 concrete sub-questions.
2. For each, browse to the most authoritative source you can find and read the page.
3. Cross-check any surprising claim on a second, independent page.
4. Reply with a short summary, then a bullet list of findings, each with its source URL in parentheses.
